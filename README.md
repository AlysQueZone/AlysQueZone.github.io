# AlysQueZone

Шуточная биржа приветов Twitch-канала [alysque](https://www.twitch.tv/alysque).

Стример здоровается с чатом — его привет это ценность. Чатерсы выставляют приветы на биржу и перепродают их за пивкойны.

> В РФ часть Supabase заблокирована, поэтому сайт работает только с VPN.

## Тех

- Статический сайт на Astro (GitHub Pages): вёрстка статична, витрина и лоты читают Supabase в браузере.
- Полностью вайбкодится через <https://github.com/mattpocock/skills>

## Локальный запуск

Нужны Node.js 18+ и npm.

Плюс `PUBLIC_SUPABASE_URL` и `PUBLIC_SUPABASE_PUBLISHABLE_KEY` в `.env` (шаблон — `.env.example`) — без них сайт не соберётся.

```bash
npm install
npm run dev
```

Открыть http://localhost:4321

## Ещё команды

```bash
npm run build    # сборка в dist/
npm run preview  # предпросмотр сборки
```

## Скиллы

Скиллы — это готовые сценарии, по которым агент делает типовые задачи. Запускать их вручную не нужно: опиши задачу и назови скилл — агент сам подтянет его инструкции. В проекте два набора.

**Инженерные** — из [mattpocock/skills](https://github.com/mattpocock/skills), лежат в `.agents/skills/`:

- `ask-matt` — не знаешь, что выбрать: подберёт скилл под задачу.
- `grill-with-docs` — расспросит про идею и зафиксирует решения в `CONTEXT.md` и ADR.
- `to-spec` → `to-tickets` → `implement` — превратить идею в спеку, тикеты и код (`implement` внутри гоняет `tdd`).
- `diagnosing-bugs` — разобраться со сложным или плавающим багом.
- `code-review` — ревью изменений: стандарты репозитория + соответствие задаче.
- Плюс `research`, `triage`, `prototype`, `handoff`, `wizard`, `wayfinder`, `teach` и другие.

**Дизайн и UI** — из [uipro-cli](https://www.npmjs.com/package/uipro-cli), лежат в `.opencode/skills/`:

- `ui-ux-pro-max` — стили, палитры, шрифты, UX-правила, проверка интерфейса.
- `ui-styling` — вёрстка: Tailwind и доступные компоненты.
- `design-system` — токены и спецификации компонентов.
- `design`, `brand`, `banner-design`, `slides` — логотипы, айдентика, баннеры, презентации.

Этих скиллов в гите нет: после клона — `npx uipro init --ai opencode`, обновление — `npx uipro update`.

### Пример

На карточке лота дублируется цена — хочется убрать.

1. «Используй `grill-with-docs`: давай решим, как убрать дублирование цены на карточке.» Агент задаёт вопросы и записывает решения в `CONTEXT.md` и `docs/adr/`.
2. «Теперь `implement`.» Агент собирает тикет, пишет тесты, код, прогоняет `code-review` и коммитит.
3. Если непонятно, как это должно выглядеть: «Посмотри `ui-ux-pro-max` и предложи варианты карточки.»

Коротко: вместо заучивания команд достаточно назвать скилл — агент сделает остальное.
