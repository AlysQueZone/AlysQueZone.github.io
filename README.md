# AlysQueZone

Шуточная биржа приветов Twitch-канала [alysque](https://www.twitch.tv/alysque).

## Тех

- Статический сайт на Astro (GitHub Pages): вёрстка статична, витрина и лоты читают Supabase в браузере.
- Полностью вайбкодится через нижеупомянутые скиллы.

## Локальный запуск

Нужны Node.js 18+ и npm.

Плюс `PUBLIC_SUPABASE_URL` и `PUBLIC_SUPABASE_PUBLISHABLE_KEY` в `.env` (шаблон — `.env.example`) — без них сайт не соберётся.

```bash
npm install
npm run dev
```

Открыть <http://localhost:4321>

### С локальной базой

`just` поднимает Supabase в Docker, накатывает миграции и заливает карточки из `content/lots.toml`, а затем запускает dev против локальной БД:

```bash
just run-local   # db-up + dev на локальной БД
just db-up       # только поднять БД и до-накатить миграции
just db-reset    # чистая БД: миграции + сид (данные теряются)
just db-stop     # остановить БД
```

Вход через Twitch работает и локально: в `.env` нужны `TWITCH_APP_CLIENT_ID` и `TWITCH_APP_CLIENT_SECRET`, а в Twitch-приложении — redirect `http://localhost:54321/auth/v1/callback`.

Уведомления в Telegram тоже работают локально: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ADMIN_CHAT_ID` из `.env` заливаются в локальный Vault (`just db-vault`; автоматически в `run-local` и после `db-reset`).

После `just db-reset` локальные сессии устаревают (БД чистая) — выйди и войди через Twitch заново.

## AI Скиллы

**Инженерные** — из [mattpocock/skills](https://github.com/mattpocock/skills), лежат в `.agents/skills/`:

Понять задачу:

- `ask-matt` — не знаешь, что выбрать: подберёт скилл под задачу.
- `grill-with-docs` — расспросит про идею с пристрастием и запишет решения в `CONTEXT.md` и ADR.
- `grill-me` — то же интервью, но без записи документов.
- `grilling` — сам приём «допроса», если нужен без обёртки.
- `wait-what` — если агент объяснил непонятно: перескажет проще.

Сделать:

- `to-spec` — собрать обсуждение в описание задачи.
- `to-tickets` — разбить его на отдельные задачи со связями.
- `implement` — выполнить задачу (внутри пишет тесты через `tdd`).
- `tdd` — сначала тест, потом код.
- `code-review` — проверить изменения: по стандартам проекта и по исходной задаче.
- `prototype` — быстрый одноразовый макет, чтобы проверить идею или внешний вид.

Разобраться и навести порядок:

- `diagnosing-bugs` — разобраться со сложным или плавающим багом.
- `resolving-merge-conflicts` — разрулить конфликт слияния или перебазирования.
- `triage` — разобрать входящие issue и чужие правки в понятные задачи.
- `research` — изучить вопрос по надёжным источникам и оставить отчёт в проекте (можно фоном).
- `wayfinder` — распланировать очень большой объём работы картой решений.

Внутреннее устройство:

- `improve-codebase-architecture` — найти места, где код стоит упростить, и показать отчётом.
- `codebase-design` — язык для проектирования внутренних границ кода.
- `domain-modeling` — навести порядок в терминах проекта, вести `CONTEXT.md` и ADR.

Служебное:

- `handoff` — упаковать текущий разговор в файл, чтобы продолжить в другой сессии или папке.
- `wizard` — пошаговый bash-скрипт для дел, которые может сделать только человек (доступы, панели, миграции).
- `to-questionnaire` — анкета для человека, чьи знания нужны.
- `teach` — учить новой теме, используя папку как рабочее место.
- `writing-for-agents` — как писать документы для агентов (скиллы, `AGENTS.md`).
- `setup-matt-pocock-skills` — разовая настройка проекта под эти скиллы.
- `setup-pre-commit` — поставить проверки, которые запускаются перед коммитом.

Рядом в `.agents/skills/` лежат два скилла от Supabase — `supabase` и `supabase-postgres-best-practices`: они про базу данных и правила работы с ней.

**Дизайн и оформление** — ставит отдельная программа [uipro-cli](https://www.npmjs.com/package/uipro-cli), скиллы лежат в `.opencode/skills/`.

Это большая база подсказок, которую агент ищет под конкретную задачу: готовые варианты внешнего вида (строгий, игривый, тёмный и т. д.), подборки цветов и шрифтов, правила, чтобы страницей было удобно пользоваться, примеры, как показать числа и статистику, советы под технологию проекта. Что ставят:

- `ui-ux-pro-max` — основной: подбирает внешний вид и проверяет, удобно ли получилось.
- `ui-styling` — помогает писать код оформления.
- `design-system` — следит, чтобы цвета и размеры по всему сайту были одинаковыми.
- `design` — общий: логотип, фирменный стиль, картинки.
- `brand` — голос и характер канала, чтобы тексты были «в стиле».
- `banner-design` — баннеры и обложки для соцсетей.
- `slides` — презентации.

Части скиллов нужен Python 3 — агент предупредит, если его нет.

В гите этих скиллов нет: после клона — `npx uipro init --ai opencode`, обновление — `npx uipro update`.

### Пример

На карточке лота дублируется цена — хочется убрать.

1. «Используй `grill-with-docs`: давай решим, как убрать дублирование цены на карточке.» Агент задаёт вопросы и записывает решения в `CONTEXT.md` и `docs/adr/`.
2. «Теперь `implement`.» Агент собирает тикет, пишет тесты, код, прогоняет `code-review` и коммитит.
3. Если непонятно, как это должно выглядеть: «Посмотри `ui-ux-pro-max` и предложи варианты карточки.»

Коротко: вместо заучивания команд достаточно назвать скилл — агент сделает остальное.
