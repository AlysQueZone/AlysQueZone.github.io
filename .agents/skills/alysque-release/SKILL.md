# Релиз AlysQueZone

Релиз — две ступени, бэкенд и сайт, и обе делает один идемпотентный `just release`. Контент лотов сюда не входит: `just lots-sync` публикует лоты без деплоя.

## Гейт

Деплоя нет, пока гейт красный: `just check` (типы, линт, тесты, формат) и `npm run build`, сборку прокликать в `preview` — как поднимать и щёлкать, `docs/agents/shipping.md`. Правки закоммичены.

**Готово, когда:** гейт зелёный, `main` чистый.

## 1. Закрыть CHANGELOG

Переименуй `## Внесённые изменения` в датированную секцию и создай сверху пустую — правило и формат в `AGENTS.md`.

**Готово, когда:** изменения датированы, сверху пустая `## Внесённые изменения`, коммит сделан.

## 2. `just release`

Одна команда: переключает `gh auth` на аккаунт-владельца `AlysQueZone`, пушит `main`, затем `npm run deploy` (сборка + пуш `dist` в `gh-pages`), и в конце возвращает прежний активный аккаунт даже при ошибке. Перезапуск безопасен.

**Готово, когда:** команда прошла без ошибок.

## 3. Дождаться миграций Supabase

Push в `main` — Supabase сам накатывает новые миграции. Сразу проверять бессмысленно: подожди ~60 с, затем MCP `list_migrations` — все новые версии из очереди должны появиться.

Ошибка применения встаёт всей очередью. Прочитай текст, почини ровно неприменённую миграцию (не добавляй новую) и запушь снова.

**Готово, когда:** все новые миграции в `list_migrations`.

## 4. Проверить живой сайт

GitHub Pages раздаёт ветку `gh-pages`, не `main`. Открой живой сайт и убедись, что свежие изменения видны.

**Готово, когда:** свежие маркеры видны на живом сайте.
