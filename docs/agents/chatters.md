# Ники чатерсов: реестр и резолв написания

Реестр ников — `content/chatters.toml`. Поля: `nick` — канон (как писать), `login` — ключ дедупа,
`id` — Twitch user id, `aliases` — варианты написания (кириллица, опечатки), `note` — заметка для человека
(напр. «несколько аккаунтов одного человека»).

## Правило (перед записью ника в `title` карточки)

1. Найди ник в реестре: `grep -i <подстрока> content/chatters.toml` — сначала по `nick`/`login`, потом по `aliases`. Быстрее — `just lots-title privets/<файл>.mp4`: возьмёт ник из имени файла, сверит с реестром и вернёт `title` (или покажет кандидатов).
2. Нашёл — пиши `nick` ровно так, как в реестре (`ShidouQuE`, а не `ShidouQue`/`шидоу`).
3. Не нашёл, но резолвится однозначно (кириллица/опечатка/вариант) — используй канон и **допиши свой вариант в `aliases`** этого ника: `aliases = ["шидоу"]`.
4. Неоднозначно (несколько кандидатов) — не гадай, спроси человека.

`aliases` и `note` — единственное, что правят руками; остальные поля перегенерирует скрипт.

## Резолв ника по фразе из чата VOD

Если имя файла не даёт однозначного ника, а фраза привета известна: возьми характерный кусок фразы и найди, кто её сказал в чате VOD.

    just chatters-find --vod <id> --until 1800 "надеюсь меня не переедут"

Печатает время, `@display (login)` и канон по реестру; фраза ищется по нормализованной подстроке (регистр, пунктуация и эмоуты не важны). `--until <сек>` ограничивает первыми минутами (быстрее), `--chat <chat.json>` работает по готовому дампу. Нашёл — действуй по правилу выше: пиши канон, при необходимости допиши свой вариант в `aliases`.

## Пополнение реестра

`just chatters-sync --vod <id>` (или `--chat <chat.json>`) добавляет новые ники и проставляет `id`;
идемпотентно, `aliases` не трогает. Источник чата — `docs/agents/twitch-sources.md`.
