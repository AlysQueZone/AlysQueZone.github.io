# Экономика биржи: гамба-звуки и витрина

Канон математики — `CONTEXT.md` (Экономика: пивкойн, гамба, перекуп, комиссия, вход). Витрина обязана показывать живые правила.

Звуки гамбы — рандом-пулы из констант `GAMBA_*_SOUNDS` в `src/lib/gamba.ts` (спин / выигрыш / джекпот / проигрыш); перечень файлов — сама константа, дублировать его здесь не нужно. Нюансы: возврат церемониально равен проигрышу и звучит lose-пулом (худший исход таблицы I, мимо нет); `gamba-win-taktak.mp3` — фраза кручения «тактактакуе» (имя исторически с префиксом win); `gamba-bg.mp3` — one-shot вариант спина, не луп; источник фраз — MemeAlerts webm → `ffmpeg -vn libmp3lame`.

Математика в UI — из одних рук: бегущая строка-лог, hero-бейджи, модалка «Правила биржи» показывают живые правила (комиссия биржи, рост цены, гамба, вход). Меняешь механику — обнови все три места и `CONTEXT.md`, иначе витрина врёт (кейс: бейдж «+10%» пережил введение комиссии).
