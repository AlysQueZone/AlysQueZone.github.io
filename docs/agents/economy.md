# Экономика биржи: гамба-звуки и витрина

Канон математики — `CONTEXT.md` (Экономика: пивкойн, гамба, перекуп, комиссия, вход). Витрина обязана показывать живые правила.

Звуки гамбы — рандом-пулы из констант `GAMBA_*_SOUNDS` в `src/lib/gamba.ts` (спин / выигрыш / джекпот / проигрыш); перечень файлов — сама константа, дублировать его здесь не нужно. Нюансы: возврат церемониально равен проигрышу и звучит lose-пулом (худший исход таблицы I, мимо нет); `gamba-win-taktak.mp3` — фраза кручения «тактактакуе» (имя исторически с префиксом win); `gamba-bg.mp3` — one-shot вариант спина, не луп; источник фраз — MemeAlerts webm → `ffmpeg -vn libmp3lame`.

Математика в UI — из одних рук: бегущая строка-лог, модалка «Правила биржи» и строка награды в форме заявки показывают живые правила (комиссия биржи, рост цены, гамба, вход). Меняешь механику — обнови все три места и `CONTEXT.md`, иначе витрина врёт (кейс: бейдж «+10%» пережил введение комиссии).

## Награда за принятый привет

Принятие заявки (`just submission <id>`) после `accept_submission` вызывает RPC `pay_submission_reward` — только `service_role`, идемпотентный по `submissions.rewarded_at`. Автору разово начисляется **+500 Пивкойнов** (строка леджера `submission_bonus`); повторный запуск пайплайна не платит дважды, отказ выплат не делает.

**Роялти** — 3% цены сделки автору привета за **первые три перекупа** лота (ставка `public.royalty_rate()`, строка леджера `royalty_credit`). Источник — комиссия биржи: с продавца по-прежнему списываются полные 7% (`commission_burn`), а 3% из них уходят автору, поэтому нетто сгорает 4%, и продавец получает столько же, сколько раньше. После третьего перекупа роялти нет; у автора без счёта (аккаунт удалён) выплат нет, профиль ему не создаём.

Ставки комиссии/роялти и бонус — зеркала `src/lib/prices.ts` (`COMMISSION_RATE`, `ROYALTY_RATE`, `ROYALTY_PURCHASES`, `SUBMISSION_BONUS`). Рост цены в клиенте не зеркалится: канон — `public.next_lot_price` (`docs/adr/0007`), числа витрины берутся из правил. Меняешь механику — обнови SQL-функцию (или зеркало) и места показа.
