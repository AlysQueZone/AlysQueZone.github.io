# Всплывающие уведомления — один модуль: `src/lib/notice.ts`

Три копии одного понятия (перекупы, принятые заявки, покупка) сведены в один модуль. Два входа — у них разная механика, общие кишки внутри:

- `showCornerNotice` — стек в правом нижнем углу: максимум `MAX_NOTICES`, старые вытесняются, авто-скрытие 30с, hover удерживает; шапка, кнопка-действие (перекуп — её клик закрывает окошко), крестик, ключ для `closeNotices`.
- `showSpotNotice` — одиночная плашка: снизу текстовая (2.6с), по центру — видео-вариант (до `ended`, 30с страховка); тон рамки, картинка-эмоут, клик-вне и Escape.

Стек, таймеры, вытеснение, крестик, видео и клик-вне — реализация; вызывающий говорит только «что показать». TTL угла унифицирован (было 20с у перекупов и 30с у заявок — стало 30с): разъехавшиеся числа и были симптомом. Тексты — только `textContent` (ники и заголовки лотов правит пользователь). Специфика поверхностей остаётся тонкими адаптерами: строка продавца — `outbid-event.ts`, кнопка возврата — `outbid-notices.ts`, подача заявок — `submission-notice.ts`.

## Considered Options

- **Три копии на местах** (было): интерфейс каждой — почти вся её реализация; TTL и вёрстка расходятся при правке одного места.
- **Одна функция с `place` и десятком опций**: угол и центр — разная механика (стек/одиночка, hover/клик-вне), одна сигнатура стала бы списком параметров вместо интерфейса.
- **Общий модуль только для угла, покупка со своей копией**: понятие снова разорвано — видео-вариант остался бы особым случаем.
