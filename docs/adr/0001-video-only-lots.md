# Видео-мемы only: без текстовых лотов, редкости и эмоутов карточек

Все лоты теперь — приветы с видео (`video_url` обязателен по смыслу, не по NOT NULL): 10 карточек без видео удалены вместе с их покупками, колонки `meme_text`/`rarity` и маппинг «эмоут карточки» (`LOT_EMOTES`) вычищены. Редкость больше не различает ценность — сортировка витрины только по цене.

## Considered Options

Удалять физическим `DELETE` с каскадом покупок vs скрывать флагом: выбран `DELETE` — шуточная биржа, история текстовых лотов не load-bearing, а флаг оставил бы мёртвые ветки в коде и схеме.
