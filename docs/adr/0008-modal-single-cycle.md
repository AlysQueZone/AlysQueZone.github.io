# Цикл окна-диалога — один модуль: `src/lib/modal.ts`

Открытие, закрытие, Escape, клик по затемнению и фокус — один цикл на четыре окна: покупка (`BuyModal`), гамба, правила биржи и окно ежедневного входа. `createModal(root, hooks)` возвращает handle (`open(opener?)`/`close`); компонент объявляет разметку и своё состояние в `onOpen`/`onClose`, а `opener` (для программных кликов) задаёт, куда вернуть фокус. Классы `hidden`/`flex`, `role=dialog` и `aria-modal` (если их нет), `tabindex="-1"` пустому корню, Escape, клик-вне, первый фокус и возврат фокуса — реализация модуля. `modal-focus.ts` растворён внутри: ловушка Tab — часть цикла.

Контракт разметки: кнопки закрытия носят `data-modal-close`, клик по самому корню (затемнению) закрывает окно. Слушатель кликов — на корне, а не на `document`: клик, которым окно открыли, в него уже не попадёт (путь события посчитан до появления окна в DOM) — отложка из окна ежедневного входа больше не нужна.

Открытые окна живут стеком: Escape, Tab и клик-вне обслуживают верхнее; нижнее окно не снимаем и не трогаем. Так автоматическое окно ежедневного входа может всплыть поверх открытой покупки и не отбирать у неё управление. Прежде каждая копия вешала свой Escape на `document` — одно нажатие закрывало все открытые окна разом (у всплывающих уведомлений свой Escape, это `docs/adr/0005`). Стек — единственный вход и выход окна: узел, снесённый мимо цикла, оставил бы в стеке мёртвую запись, поэтому окно входа закрывает прежнее окно через handle, а не удалением узла.

## Considered Options

- **Четыре копии на местах** (было): цикл дублировался в `BuyModal`, `GambaModal`, `RulesModal` и окне входа; мелочи (набор классов, aria, порядок фокуса) расходились, и расхождения никто не ловил.
- **Одно окно на страницу** (открытие нового закрывает прежнее): автоматическое окно входа закрывало бы открытую покупку и теряло её намерение — стек честнее.
- **`modal-focus.ts` плюс оркестратор снаружи**: два владельца одного цикла — Escape и клик-вне остались бы у компонентов, расхождения продолжались бы.
- **Делегированное открытие `data-modal-open`**: у окон разные точки открытия и разное содержимое (намерение покупки, живые строки гамбы) — открытие осталось у компонентов, модуль владеет только циклом.
