# Ошибки транспорта — один классификатор, доменные виды — у мапперов: `src/lib/errors.ts`

Разбор ошибки на «текст / офлайн / нет входа» живёт в одном модуле: `errorText`, `isOfflineError` (маркеры транспорта + `TypeError` от fetch), `isNoAuthError` (JWT, RLS, «not authenticated», «no twitch identity»). Три маппера (покупка, гамба, заявки) и `DailyLogin` зовут его; доменные виды — пауза, лимит, не хватает Пивкойнов, сроки заявки, а также `permission denied`/`foreign key` как «истёкшая сессия» заявок — остаются у своих мапперов: их знает только своя поверхность, общий классификатор их не угадывает.

Набор маркеров «нет входа» — объединение прежних копий: он намеренно шире, чем был у гамбы/заявок (`no twitch identity`), потому что это тот же вход, а не отдельная болезнь. Офлайн-маркеры и `TypeError` — общие: правка офлайн-гейта теперь одна.

## Considered Options

- **Оставить копии** (было): правка офлайн-гейта — четыре захода; списки и порядок проверок расходятся молча.
- **Общий классификатор всех видов** (включая доменные): «не хватает Пивкойнов» и «пауза» — язык своих триггеров; общий модуль стал бы свалкой серверных текстов.
- **Классификатор по строке, а не по ошибке** (`isOfflineText(low)`): `TypeError` от fetch без текста-маркера потерялся бы, и проверка `err instanceof TypeError` снова разошлась бы по копиям.
