# AlysQueZone — спека запуска (фейк-биржа приветов)

Собрана из wayfinder-карты `.scratch/alysque-launch/map.md` (все 7 decision-тикетов закрыты). Дальше — только build-тикеты 08–12, решений не осталось.

## Что строим

Шуточная «биржа приветов» twitch-канала alysque. Три статических экрана, бэкенда нет — UI фейкает бэкенд на хардкоде. Выигрышный прототип: вариант A (`.scratch/alysque-launch/prototype/birzha-prototype.html?variant=A`).

## Стек и деплой

- Astro 7.2.9 + TypeScript 5 + Tailwind 4.3.3 (через `@tailwindcss/vite`, токены в CSS `@theme`), Node 22. Детали и структура — тикет 03.
- Деплой: только GitHub Pages, `npm run deploy` (= `astro build` + `gh-pages -d dist`), прод-URL `https://alysquezone.github.io/` (user-pages на аккаунте `AlysQueZone`, репо `AlysQueZone.github.io`), в `astro.config.mjs` `base: '/'`. Surge-зеркало из тикета 01 отменено решением человека (не используем). Проверка открытия из РФ — тикет 12.

- Темный фон `#0E0E10`/`#18181B`, текст `#FFFFFF`/`#EFEFF1`, CTA `#9146FF`.

- При scaffold снять пипеткой 2–3 цвета с баннера/аватара (ссылки в тикете 02) и подвинуть токены.

## Фейк-покупка (финал, «всё вместе, но дешево»)

`src/lib/wallet.ts`, всё в `localStorage`: баланс `pivkoiny_balance` (старт 1000). Клик «купить» → модалка «Потратить N Пивкойнов?» → Да → баланс минус, confetti, лот падает в «Мои приветы» (инвентарь в `localStorage`), в историю лота локально дописывается «ты → владелец», тост в тоне канала. Не хватает → «Не хватает Пивкойнов, пойжем жоско на стрим». ЛУК — кнопка disabled «НЕ ПРОДАЕТСЯ».

## Экраны (вариант A)

1. Лендинг `src/pages/index.astro`: hero («БИРЖА ПРИВЕТОВ. СТРИМ ВКЛЮЧИЛСЯ, А ТЫ?» + чемодан «продам привет»), «как это работает» (3 шага), топ приветов, CTA на биржу.
2. Биржа `src/pages/lots/index.astro`: сетка `LotCard`, бейдж редкости, моно-цены.
3. Карточка `src/pages/lots/[id].astro` (`getStaticPaths` по lots.json): владелец, история, кнопка купить + модалка.
4. `404.astro`. Корзины/профиля нет (out of scope карты).
