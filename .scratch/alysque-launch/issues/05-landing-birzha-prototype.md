## Question

Сделать дешевый rough-прототип 3 экранов фейк-UI с брендингом: лендинг (hero + как это работает + топ приветов + CTA на биржу), биржа (сетка лотов), карточка привета (владелец, история перепродаж, кнопка купить). Данные — реальные 10 лотов из закрытого тикета про экономику (схема + ники + цены там, плейсхолдеры больше не нужны).

HITL: вызвать skill `prototype`, положить артефакт (папка или ветка `prototype/<name>`, ссылку приложить к ответу), показать человеку на реакцию. Дождаться 02 (брендинг) и 03 (стек).

## Answer

Прототип готов (skill `prototype`, ветка UI, sub-shape B — шелла приложения в репо нет, поэтому один throwaway-файл вместо Astro-роутов; допущение записано в шапке файла):

- Артефакт: `.scratch/alysque-launch/prototype/birzha-prototype.html` (15 КБ, один файл, zero-deps). Запуск: дабл-клик или `python3 -m http.server` + открыть файл. Репо без коммитов — throwaway-ветку `prototype/*` не создавал, артефакт лежит рядом с картой.
- 3 структурно разных варианта через `?variant=A/B/C` + плавающий свитчер (стрелки, `←/→`, шарится URL): A — Hero + сетка карточек + деталка лота; B — сайдбар + плотные строки с моно-ценами; C — чат-лента в тоне канала. Состояние видно всегда: `variant= / balance= / lots=` в правом углу.
- Данные реальные из тикетов: 10 лотов (8 обычных 100-500, 1 редкий 750, ЛУК 9999 not_for_sale), ники все по максимуму, палитра `#0E0E10`/`#9146FF`/пивное золото, localStorage-кошелек со старта 1000, модалка + тосты в тоне канала, без дисклеймера (решение юзера).
- Handover: покликай `?variant=A/B/C` и скажи победителя (можно «шапку из B с сеткой из A») — победитель сложится в спек и Scaffold Astro из тикета про стек; проигравшие останутся только в этом файле.
