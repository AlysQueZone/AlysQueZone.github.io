# UX гонок и свежести Владельца

Type: grilling
Status: resolved
Blocked by: 01

## Question

Какой UX совместного Владельца приемлем: оптимистичная покупка сразу + фоновая синхронизация, polling при открытии, realtime-подписка, ручная кнопка «обновить»? Что видит второй чатерс, если лот только что купили (проигранная гонка, устаревший владелец, ошибка записи)? Что происходит при офлайне/блоке сервиса из РФ — молчаливый fallback на localStorage или честная ошибка?

## Answer

Свежесть — Realtime-подписка Supabase на таблицу лотов + refetch при открытии/возврате фокуса; кнопки «обновить» нет. Гонка — last-write-wins, проигравший получает тост «Лот только что забрал X за N — забрать за N+10%?» с переоткрытием модалки по новой цене (гонка — штатная ситуация, не ошибка). Покупка — только после confirm сервера (pending-статус, успех/confetti после записи; согласуется с fail-closed). Офлайн/блок и отсутствие сессии — как решено ранее: честная ошибка + запрет покупки, витрина открыта. Решено граллингом 2026-09-06, все ответы — рекомендованные.
