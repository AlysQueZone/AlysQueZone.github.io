## Decisions so far

- [Кнопка Deploy to production в Supabase: включать ли](.scratch/polish-01/issues/01-supabase-deploy-button.md): включать после чеклиста — неприменённые миграции применит сама при мерже в `main`.
- [Монетка Пивкойна не видна у части чатерсов](.scratch/polish-01/issues/02-pivkoin-emoji-fallback.md): кружка 🍺 вместо 🪙 везде.
- [Слова вместо кулдауна и тоста](.scratch/polish-01/issues/03-ui-wording.md): канон — «пауза» (в UI только «Жди N с» / «Подожди N с», с человеком — «кулдаун») и «всплывающее уведомление»; глоссарий обновлён (поправка после закрытия).
- [Перезарядка на лот с честным таймером на кнопке](.scratch/polish-01/issues/04-per-lot-cooldown-button.md): кулдаун per-(user,lot) 30с (миграция триггера), таймер из shared-истории + ошибка как правда, чужой выкуп таймер не трогает; кнопка «Забрать за N 🍺» / «Жди N с» / «Лимит: 10 покупок за 10 минут».
- [Мои приветы только из базы](.scratch/polish-01/issues/05-my-greetings-from-db.md): источник — текущий Владелец (owner_uid == сессия), RLS без изменений, пустые состояния текстами, локальный инвентарь удалить (баланс/Гамба живут).
- [Алерт «твой лот перекупили»: звук мема + уведомление в углу](.scratch/polish-01/issues/06-outbid-alert.md): триггер — Realtime-смена Владельца (был моим), звук mp3 из webm через ffmpeg, уведомление справа-снизу + кнопка перекупа, макс 3, свёрнутая — счётчик без звука.
