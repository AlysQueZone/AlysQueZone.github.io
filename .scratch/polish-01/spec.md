## Problem Statement

После переезда на shared-Владельца накопились 7 пунктов обратной связи:
кнопка Deploy to production в Supabase (включать ли), 🪙 не виден у части чатерсов,
слово «кулдаун» непонятно, кулдаун не на кнопке и нечестный, кулдаун глобальный
вместо per-lot, «Мои приветы» оторваны от БД, нет звука/уведомления о перекупе.
Плюс запрет слов «тост»/«передышка» в UI.

## Solution

Шесть решений карты, код не тронут (это делает имплементация ниже):
Deploy — ВКЛ после чеклиста; монетка — 🍺; в UI «пауза»/«Жди N с»/«Подожди N с»,
с человеком — «кулдаун»; кулдаун — per-(user,lot) 30с с честным таймером на кнопке;
«Мои приветы» — текущий Владелец из БД; перекуп — уведомление в углу + свой звук.

## User Stories

1. Как владелец проекта, я хочу ВКЛ Deploy to production после чеклиста, чтобы мерж в `main` сам применял миграции.
2. Как Чатерс, я хочу видеть цены и баланс с 🍺 вместо 🪙 везде, чтобы монетка отображалась на любом устройстве.
3. Как Чатерс, я хочу понятные фразы «Жди N с» / «Подожди N с» вместо «кулдауна» и «тоста», чтобы не гуглить сленг.
4. Как залогиненный Чатерс, я хочу покупать разные лоты без задержки, а повтор того же лота — через честный 30с-таймер прямо на кнопке, чтобы понимать, сколько ждать.
5. Как Чатерс, я хочу видеть «Мои приветы» из БД (где я текущий Владелец), чтобы список не врал после перекупов.
6. Как Чатерс, чей лот перекупили, я хочу уведомление в углу + звук мема с кнопкой перекупа, чтобы ответить сразу.
7. Как Чатерс со свёрнутой вкладкой, я хочу тихий счётчик пропущенных перекупов без звука, чтобы не пугаться.

## Implementation Decisions

- Монетка: заменить `🪙` → `🍺` в `LotCard.astro`, `BuyModal.astro`, `lots/index.astro`, `lots/[id].astro` (5 мест). SVG/7TV не берём.
- Термины: канон — «пауза» (глоссарий `CONTEXT.md`, раздел «Покупка»), в UI только фразы «Жди N с» (кнопка) / «Подожди N с» (уведомление); идентификаторы переименовать (`buy-toast` → `buy-notice`, `showToast` → `showNotice`, `toastTimer` → `noticeTimer`, `cooldownTimer` → `pauseTimer`, комменты без «кулдаун»/«тост»).
- Кулдаун-сервер: новая миграция — в `enforce_purchase_rules` проверка per-(user,lot): `buyer_uid = v_uid and lot_id = NEW.lot_id and created_at > now() - 30s`; текст ошибки с секундами для парсинга (`parseCooldownSec` уже есть). Кап 10/10мин без изменений.
- Кулдаун-клиент: кнопка — три состояния «Забрать за N 🍺» / «Жди N с» (disabled + живой отсчёт) / «Лимит: 10 покупок за 10 минут» (disabled); таймер — проекция из shared-истории (моя последняя покупка этого лота, живо по Realtime) + серверная ошибка как правда; чужой выкуп таймер не трогает.
- Мои приветы: секция = лоты где `owner_uid == uid` сессии (клиентский фильтр, RLS без изменений); гость — «Войди через Twitch — тут будут твои приветы», пусто — «Пока пусто — забери первый привет ниже»; бейдж «ТВОЙ» как есть; из `BuyModal` убрать запись локального инвентаря/истории, `wallet.ts` — только баланс/Гамба.
- Алерт перекупа: триггер — Realtime-смена Владельца лота, где я был прошлым Владельцем; звук — `ffmpeg -i in.webm -vn -codec:a libmp3lame -q:a 5 public/sounds/outbid.mp3` из `https://cdns.memealerts.com/p/644a705d5c87d011a6d1fb60/1f02feb4-b11f-46f3-b3dc-c6e66bfebcc1/alert_orig.webm`, играть `new Audio` после первого взаимодействия; уведомление справа-снизу «Твой лот перекупили! X забрал Y за N 🍺 — забрать за M 🍺?» + кнопка перекупа; макс 3, старые вытесняются; `document.hidden` — без звука, счётчик, сброс при возврате. Только онлайн.
- Deploy-чеклист (человек, дашборд): `db pull` → идемпотентность сид-миграции → Working directory `.` → production-ветка `main` → тумблер → required status check → тестовый мерж.

## Testing Decisions

- После каждого тикета: `npm run build` зелёный + grep отсутствия `🪙`/`кулдаун`/`тост`/`передышка` в UI-текстах (внутреннее «кулдаун» допустимо только в комменте тикета, не в коде).
- Финал: двухбраузерный чеклист (вход, покупка, per-lot пауза с таймером, перекуп с алертом и звуком во 2-м браузере, «Мои приветы» честно обновились, ЛУК закрыт) + открыть из РФ без VPN.
- Миграция кулдауна: прямой INSERT раньше 30с на тот же лот — отклонён; на другой лот — принят.
