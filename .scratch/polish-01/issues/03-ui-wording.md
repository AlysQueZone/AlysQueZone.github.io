# Слова вместо кулдауна и тоста

Type: grilling
Status: resolved
Blocked by: none

## Question

Два слова в UI запрещены/не нравятся: «кулдаун» (тех-сленг, непонятно чатерсам) и «тост» (внутренний жаргон, заменяем на «всплывающее уведомление»). Какие канонические термины вместо них во всех текстах, спеке и глоссарии `CONTEXT.md`? Кандидаты для кулдауна: «перезарядка», «пауза перед перекупом», «задержка», «подожди N сек»; для уведомления: «всплывающее уведомление», «оповещение», «подсказка». Решить единожды (grilling + domain-modeling, обновить CONTEXT.md), дальше все тикеты используют только новые термины. Учесть склонения и короткие формы для кнопки («Жди 12 с» vs «Перезарядка 12 с»).

## Answer

Канон: «кулдаун» → **«передышка»** («Передышка лота: подожди N с»; «перезарядка» отвергнута человеком, взята «передышка» из раунда 2); «тост» → **«всплывающее уведомление»**. Кнопка — коротко **«Жди N с»**. Идентификаторы в коде переименовать (`buy-toast` → `buy-notice`, `showToast` → `showNotice` и т.п.) при имплементации, чтобы жаргон не возвращался. Глоссарий обновлён: `CONTEXT.md` — раздел «Покупка» (Передышка, Всплывающее уведомление). Решено гриллингом 2026-09-07, раунды 1–2.

**Поправка 2026-09-07 (после закрытия, до имплементации):** «передышка» отвергнута человеком и в UI; с человеком общаемся словом «кулдаун», в UI — дружелюбно без зауми. Новый канон: существительное **«пауза»** там, где существительное нужно; в интерфейсе — только фразы **«Жди N с»** (кнопка) и **«Подожди N с»** (уведомление). `CONTEXT.md` переписан: Пауза вместо Передышки. Выбор делегирован агенту из шорт-листа «жди/подожди/пауза».
