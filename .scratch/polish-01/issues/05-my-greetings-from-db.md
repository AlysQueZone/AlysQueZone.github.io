# Мои приветы только из базы

Type: grilling
Status: resolved
Blocked by: none

## Question

Человек решил: «Мои приветы» подключаем к БД, локальный legacy выбрасываем без мержа. Что именно становится источником правды: таблица покупок по моему twitch_id (все мои выкупы) или текущее владение (лоты, где я — Владелец)? Решить: запрос и RLS (вижу только свои строки или всё + фильтр на клиенте), что видит гость без сессии и что — залогиненный без покупок (пустые состояния), бейдж «ТВОЙ» остаётся ли, сортировка/лимиты хвоста, судьба локального `wallet.ts` для этого блока (удалить чтение полностью). Разворот прошлого решения «Мои приветы локальные» — зафиксировать явно.

## Answer

Всё рекомендованное, принято 2026-09-07: (1) «Мои приветы» = лоты, где я **текущий Владелец** (перекупленный пропадает из списка; история моих покупок — в историях лотов); (2) фильтр — **owner_uid == uid сессии**, RLS менять не надо (покупки/лоты читаемы всем, фильтр на клиенте); бейдж «ТВОЙ» остаётся и консистентен с секцией; (3) пустые состояния показываем всегда: гость — «Войди через Twitch — тут будут твои приветы», залогиненный без лотов — «Пока пусто — забери первый привет ниже»; (4) `wallet.ts` живёт дальше только ради баланса Пивкойнов и Гамбы — запись/чтение локального инвентаря и истории из `BuyModal`/секции убрать, успех пишет только в shared. Разворот решения «Мои приветы локальные» (shared-state тикет scope) зафиксирован явно; локальный legacy удаляется без мержа.
