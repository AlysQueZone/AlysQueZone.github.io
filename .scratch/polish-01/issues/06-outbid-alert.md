# Алерт «твой лот перекупили»: звук мема + уведомление в углу

Type: prototype
Status: resolved
Blocked by: 03, 05

## Question

Когда у меня перекупили лот, хочу всплывающее уведомление в углу + отдельный звук — этот мем-лот: https://cdns.memealerts.com/p/644a705d5c87d011a6d1fb60/1f02feb4-b11f-46f3-b3dc-c6e66bfebcc1/alert_orig.webm (человек прислал webm; решить как играть: вытащить mp3 через ffmpeg как принято в AGENTS.md, играть webm напрямую, автоплей-политики браузеров). Решить и показать дешёвым прототипом: триггер — Realtime-событие смены Владельца на лот, где я был прошлым Владельцем (нужен ответ тикета 05 что считать «моим»); вид уведомления (угол, текст «X забрал Y за N — забрать за N+10%?», кнопка перекупа); троттлинг при массовых перекупах; поведение при свёрнутой вкладке (тихий бейдж vs звук). Заблокировано: терминологией (03) и источником «моих» (05).

## Answer

Принято как в прототипе, 2026-09-07: триггер — Realtime-смена Владельца лота, где я был прошлым Владельцем (консистентно с «мои = текущий Владелец»); звук — вытащить mp3 из присланного webm через `ffmpeg -i in.webm -vn -codec:a libmp3lame -q:a 5 public/sounds/outbid.mp3`, играть через `new Audio` (паттерн BuyModal/GambaModal); автоплей — звук только после первого взаимодействия со страницей. Вид — всплывающее уведомление справа-снизу: «Твой лот перекупили! X забрал Y за N 🍺 — забрать за N+10%?» + кнопка «Забрать за M 🍺» (переоткрывает покупку); троттлинг — максимум 3 уведомления, старые вытесняются; свёрнутая вкладка — без звука, только счётчик пропущенных, сбрасывается при возврате. Только онлайн (офлайн-история — в тумане карты). Прототип: `.scratch/polish-01/prototype/outbid-alert.html` (throwaway).

**Поправка 2026-09-07 (обратная связь, зафиксирована в имплементации):** «свёрнутая — без звука, только счётчик» отменено человеком: звук играет и в фоне, пропущенное показывается окошками при возврате + живёт в колокольчике с историей.
