# Монетка Пивкойна не видна у части чатерсов

Type: prototype
Status: resolved
Blocked by: none

## Question

Emoji 🪙 не отображается у некоторых чатерсов (шрифты/платформы без цветного emoji). Какой заменой показать цену/баланс Пивкойна всем одинаково: инлайн-SVG монетка, PNG/WebP из статичных ассетов, текстовый фолбэк («П» / «пив»), или связка emoji + фолбэк через font-stack? Прототип — дешёвый фейк-UI с 3–4 вариантами в ряд на витрине и карточке (светлая/тёмная тема), человек выбирает глазами. Учесть: 0₽, статика Astro, хотлинк на чужие CDN только для уже разрешённого (7TV/Twitch), бинарники не коммитить без нужды.

## Answer

V5 — кружка пива 🍺 вместо 🪙 везде (цены, баланс, история). Первый ряд прототипа (SVG/текст) отвергнут человеком; второй ряд выбран глазами 2026-09-07. SVG-монетки с кружкой (V6/V7) и 7TV-эмоут (V8) не берём. Замена — строкой `🪙` → `🍺` в `LotCard.astro`, `BuyModal.astro`, `lots/index.astro`, `lots/[id].astro` (5 мест, список в сессии). Прототип-артефакт: `.scratch/polish-01/prototype/coin-fallback.html` (throwaway, в прод не тащить).
