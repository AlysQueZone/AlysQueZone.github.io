## Question

Какой TS-стайлгайд и архитектура фронта принимаем для `src/` (Astro-острова, слои, нейминг файлов, импорты/типы, соглашения по компонентам)? Решение должно быть достаточно конкретным, чтобы финальный task-тикет мог применить линтер и разложить правила по местам без новых вопросов.

## Answer

- Импорты (решено по гайдлайнам Astro, делегировано): `@/`-алиас для межпапочных импортов, относительные внутри одной папки, без `.ts`-расширений (extensionless — стиль примеров Astro-док). Implement-тикет переводит существующие `./x.ts` на это.
- `outbid-notice.ts` (512 строк) — распилить: выделить уведомления, звуки, localStorage-ключи в свои модули.
- Компоненты: зафиксировать — frontmatter (типы, пропсы, данные), разметка без логики, скрипты только для интерактива; SSR-first (островов `client:*` нет — так и держать, новые только по необходимости); имена PascalCase, пропсы типизированы.
