# 01: Лог сделок открывается с бегущей строки

**What to build:** чатерс кликает по бегущей строке и попадает на `/deals/`; страница показывает первые 20 сделок биржи, сгруппированные по дням, в раскладке D: липкая полоса дня «пивко», таблица с колонками на десктопе и карточки на телефоне. Миниатюра и название лота ведут на привет. До ответа — скелетон, пусто и ошибка — честные. Это первый сквозной путь: индекс в БД, чтение первой страницы, чистое ядро, страница.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Вся бегущая строка — ссылка на `/deals/`; у ссылки есть доступное имя, движение замирает на наведении и клавиатурном фокусе; остальные страницы не сломаны.
- [x] `/deals/` отдаёт первые 20 сделок новыми сверху, сгруппированные по локальным дням; полоса дня — `pivko` + кремовый текст, липнет под шапкой, показывает количество сделок и сумму дня.
- [x] Десктоп: таблица «Когда / Привет / Продал / Купил / Цена»; мобильный: карточки; миниатюра и название — одна ссылка на страницу привета; на мобильном карточка кликабельна целиком.
- [x] Состояния: скелетон, «Сделок пока нет — забери первый привет», «Лог не загрузился — проверь связь» с обновлением.
- [x] Миграция с индексом `purchases_time_idx (created_at DESC, id DESC)`; чтение — keyset-запрос по первой странице; новых колонок, таблиц и грантов нет.
- [x] Чистое ядро: отбор строк лога (лот, продавец, покупатель, цена, время) и группировка по дням с итогами; тесты на битые строки, «Сегодня/Вчера/дата», границы суток и год.
- [x] `just check` зелёный; `DESIGN.md` фиксирует `pivko` как фон полосы дня; `GLOSSARY.md` содержит «Лог сделок».

## Comments

Реализовано: `DealEntry`/`dealEntries`/`groupDealDays` в `src/lib/trade-history.ts`
(плюс `DEAL_PAGE_SIZE = 20`), курсор и слияние обобщены по `CursorEntry`, чтобы
те же функции работали для лога. Транспорт — `fetchDealLog` в
`src/lib/supabase.ts` с keyset-курсором и `{ ok, entries }`. Миграция —
`20261104120000_purchases_time_idx.sql` (только индекс). Страница —
`src/pages/deals/index.astro`: первые 20 сделок, липкие полосы дней `pivko` +
`cream`, таблица на `md+`, карточки на телефоне, скелетон/пусто/ошибка с
«Обновить», `role="status"`. Бегущая строка в `BaseLayout.astro` стала ссылкой
с `aria-label`, движение останавливается на hover и `:focus-visible`; правила —
`global.css`. `DESIGN.md` документирует `pivko` как фон полосы дня.

Проверено: `pnpm test` (129 тестов), `just check` (tsc, eslint, vitest,
prettier, звуки, build), preview + `agent-browser`: 20 строк, 4 дня, липкая
полоса встаёт ровно под шапкой (`--deals-sticky-top` = высоте `header`),
ссылка «Открыть лог сделок» на месте.

Отклонения/границы: live-обновления, пагинация и фильтр «Мои» намеренно не
добавлены — тикеты 02–03; `fetchDealLog` уже принимает курсор, чтобы их не
переписывать. Гостю «ТВОЙ» не показывается; uid читается из `live`.
