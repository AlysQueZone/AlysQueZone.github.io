# 02: Лог листается и обновляется сам

**What to build:** лог перестаёт быть снимком первой страницы. «Показать ещё» догружает следующую порцию, у конца списка подгрузка идёт сама, а новые сделки приезжают без перезагрузки: наверху — сразу, при прокрутке — плашкой «N новых сделок». Пролистанное не сбрасывается, дубли не появляются.

**Blocked by:** 01 (первый экран и чтение первой страницы).

**Status:** ready-for-agent

- [ ] «Показать ещё» догружает следующую страницу по курсору; кнопка блокируется на время загрузки; при приближении к концу списка страница подгружается автоматически; кнопка остаётся запасным путём.
- [ ] Дубли отсекаются по `id`; дописанные страницы не сдвигают уже показанное; пустая следующая страница не ломает состояние.
- [ ] Новые сделки из события `deals` модуля живых данных: если верх лога виден — вставляются сверху; если прокручен — копятся в плашке «N новых сделок»; клик по плашке сливает их и возвращает наверх.
- [ ] Статус загрузки и новых сделок объявляется через `role="status"` без навязчивых счётчиков.
- [ ] Курсор, слияние и дописывание обобщены так, чтобы работать и для истории лота, и для общего лога; поведение истории лота не изменилось; существующие тесты проходят.
- [ ] Новые тесты ядра: одинаковый `created_at` у соседей, пустая свежая страница, дедуп при слиянии, дописывание старой страницы.
- [ ] `just check` зелёный.
