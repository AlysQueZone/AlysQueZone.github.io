## Question

Как гарантируем новичку «купить хоть что-то за N дней»: фиксируем N и целевой сегмент (самый дешёвый лот? медиана? отдельная витрина/резерв для новичков?), нужен ли кап цен или лимит удержания топ-лотов китами, как мерим успех после (время до первой покупки, доля новичков с покупкой за неделю)?

Зачем: это критерий приёмки всего спека из Destination карты; без него комиссия и краны — цифры без якоря.

Контекст для сессии: финальный из трёх grillings; требует closed [Срез экономики](./01-srez-ekonomiki.md), [Комиссия с перекупа](./03-komissija-perekupa.md), [Краны эмиссии](./04-krany-emissii.md). После него туман «формат спека» из карты должен градуировать в prototype-тикет черновика спека.
