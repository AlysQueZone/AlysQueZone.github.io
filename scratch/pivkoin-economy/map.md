## Destination

Спек ребаланса экономики пивкойнов, готовый к имплементации: набор механик стоков и кранов + критерий «новичок может купить за N дней». Самого кода в этой карте нет — только решения.

## Notes

- Domain: `CONTEXT.md` (пивкойн, перекуп, гамба, ежедневный вход, биржа) + `docs/adr/` (особенно видео-only лоты). Новые термины (комиссия, налог, демередж, кап) — только через domain-modeling, без синонимов.
- Skills каждой сессии: `grilling` + `domain-modeling` по умолчанию; `research` — для AFK-фактуры, `prototype` — для черновика спека.
- Standing preferences (решения карты): накопленные балансы и цены не трогаем — правила только вперёд, без вайпа; фан и азарт перекупа/гамбы не ломаем — бьём по застою и инфляции, а не по желанию играть.
- Plan, don't do: тикеты резолвят решения, не пилят код. Pull «давайте уже кодить» = сигнал края карты и хендоффа.

## Decisions so far

<!-- индекс: одна строка на закрытый тикет, gist + ссылка; детали живут в тикете -->

- [Мировой опыт](./issues/02-mirovoj-opyt.md): веер антиинфляционных механик — комиссия 2–5% со сжиганием как базовый сток, затухание роста вместо капа, краны только по приборам; находки — `research/pivkoin-antinflation:scratch/pivkoin-economy/research/anti-inflation-world-experience.md`.
- [Срез экономики](./issues/01-srez-ekonomiki.md): 14 профилей (медиана 4638, max 65724), 21 лот (медиана 1561, max 30028); гамба печатает +204750/мес при паспортных −10% EV — главный станок; перекуп ~521k/мес без стока; новичок до медианы ~5–7 дней, топ-1 недостижим.
- [Комиссия с перекупа](./issues/03-komissija-perekupa.md): 7% сгорает, платит продавец, ceil минимум 1; затухание +10%×15 дальше +1; строка — живой лог ~10 сделок, математика — в модалку «Правила биржи» с кнопкой в hero; вход — в тикет 04.
- [Краны эмиссии](./issues/04-krany-emissii.md): живая таблица F (EV 206, тикет 16) — в спек урезание к EV ~90–100, ставку 100 не трогать; вход дни 1–3 → 200/200/250; старт 1000; статусный сток — второй очередь.
- [Доступность новичку](./issues/05-dostupnost-novichku.md): критерий — медиана за ≤5 дней; без капов/лимитов/резерва; метрики — медиана дней до первой покупки + доля за 7 дней, раз в месяц; сортировка по умолчанию дешёвые первые.
- [Черновик спека](./issues/06-chernovik-speka.md): финал — [spec.md](../spec.md) (реакция учтена: x10 жив, витрина случайная, комиссия статичная). Дестинация карты достигнута; дальше хендофф в имплементацию.

## Out of scope

- Вайп или срез существующих балансов и цен — ruled out решением Q3, только правила вперёд.
- Сама имплементация спека (код, миграции, UI) — карта заканчивается спеком, дальше хендофф.
- Текстовые лоты, редкость, эмоуты карточек — закрыто ADR-0001, не переоткрываем здесь.
