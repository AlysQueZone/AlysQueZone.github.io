# Аватар чатерса из Twitch

Status: ready-for-agent

## Problem Statement

В паспорте профиля вместо аватара стоит квадрат с инициалами. Инициалы читаются, но не дают узнать человека: у всех, кто входил через Twitch, аватар уже есть, и его видно в чате. Придумывать загрузку картинок не нужно — Twitch отдаёт её при входе.

## Solution

Если у счёта есть аватар Twitch, паспорт показывает его; нет аватара или картинка не загрузилась — остаются инициалы, как сейчас. Ссылка на картинку приходит из метаданных Supabase Auth (`user_metadata.avatar_url`, дубль — `picture`) и живёт в `profiles`, как подпись-логин.

## Implementation Decisions

- `profiles.avatar_url text` — nullable. Бэкфилл существующих счетов из `auth.users.raw_user_meta_data` (`avatar_url` → `picture`); пустое значение — аватара нет.
- Синк — тот же триггер на `auth.users`, что обновляет логин (вставка и изменение метаданных). Пустые метаданные прежнюю картинку не затирают: как и с логином, пустой ник хуже старого.
- Публичный read model `public_profile(uid)` возвращает `avatar_url`. Аватар — такая же публичная колонка `profiles`, как `login` и `balance` (column-грант `avatar_url`); `updated_at` и `ledger` остаются закрытыми, `private` клиентам не выдан.
- Чистое ядро профиля (`src/lib/profile.ts`) отдаёт `avatarUrl: string | null`; принимаются только `https:`-адреса (Twitch CDN), мусор и `javascript:` — `null`, то есть инициалы.
- Паспорт: тот же квадрат 64×64; внутри `<img>` с `alt=""` (ник рядом), `width`/`height`, `decoding="async"`, `referrerpolicy="no-referrer"`; без `loading="lazy"` — скрытая до `load` картинка иначе не грузится. Нет URL — инициалы; `error` у картинки — прячем её и показываем инициалы (без скачка раскладки и без повторных запросов).
- Никаких новых зависимостей, storage и прокси: картинку отдаёт CDN Twitch, URL меняется вместе с аватаром.

## Testing Decisions

- Ядро: маппинг `avatar_url` (валидный https, отсутствие, пустая строка, `http:`, мусор, `javascript:`).
- Локальный Supabase: анонимный вызов `public_profile` отдаёт `avatar_url`; бэкфилл заполняет счета с метаданными и не ломает счета без них; смена `raw_user_meta_data` обновляет картинку.
- Preview: свой/чужой профиль с аватаром и без; битый URL → инициалы; десктоп и телефон; сборка без БД остаётся зелёной.

## Out of Scope

- Загрузка собственных картинок и хостинг в Storage.
- Аватары не-Twitch провайдеров и граватары.
- Кэширование/прокси картинок, srcset и ресайз.
- Показ аватара где-либо кроме паспорта профиля (шапка остаётся текстовой).
