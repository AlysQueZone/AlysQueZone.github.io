**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Баланс читается из БД по сессии; чужой баланс недоступен, гостю деньги не отдаются (RLS-матрица тестом)
- [ ] Шапка показывает баланс из БД; витрина и покупка работают как раньше
