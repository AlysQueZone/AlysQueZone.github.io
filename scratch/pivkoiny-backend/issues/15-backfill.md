# 15: Бэкфилл счетов для юзеров до триггера

**What to build:** Чатерсы, зарегистрировавшиеся до появления триггера стартовых 1000, получают счёт задним числом: миграция создаёт профили с 1000 (+ открывающие строки леджера для инварианта) всем пользователям auth без профилей. Тестовые `81a1f6f5-f624-440a-a76b-63c5559efafc` и `1e9fab9b-4bb0-4cfb-a7ae-fc0faebd60e9` после этого видят баланс 1000, а клейм/покупка/спин на них работают.

**Blocked by:** None (can start immediately, только новая миграция).

**Status:** ready-for-agent

- [ ] Новая миграция: профили + открывающие движения для всех auth-юзеров без профилей (идемпотентна — повторный прогон ничего не дублирует)
- [ ] После миграции оба тестовых счёта имеют баланс 1000 и проходят клейм (проверено; живой чек — за человеком)
- [ ] Клейм/покупка/спин при отсутствующем профиле дают понятную ошибку, а не молчание (если это была причина залочки — починить причину, не только данные)
- [ ] На прод не накатывать; `npm run build` зелёный
