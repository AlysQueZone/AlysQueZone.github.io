## Answer

Принято как факт-основание для тикетов 04–05. Проверено исполнением: EV текущего бесплатного спина = 10500 (чистый faucet, 95% EV — джекпот); вариант A: EV 90, RTP 90%; вариант B: EV 94.5, RTP 94.5%. Решение: готовая слот-схема с фиксированной ставкой 100 — дефолт A (50/40/10 → возвраты 0/100/500, low-volatility), опция B (60/34.5/5/0.5 → 0/100/200/10000) если захочется мечты x100; daily — гибкий 7-дневный календарь 100/100/150/150/200/250/500 без сброса streak; номиналы +1000/+100000 не сохранять (ломают RTP<100% при старте 1000); ежемесячный сброс цен отклонён (ресеты — только для ладдеров, нерфы без коммуникации — backlash); перекуп +10% — перераспределение, не sink. Детали и 15 источников — в ветке `research/casino-math`, файл `scratch/pivkoiny-backend/research/casino-math.md`. Открытое (не здесь): server-authoritative спин/RNG/леджер, PAR-sheet + симуляция перед мёржем, телеметрия faucet/sink — ушло в тикет формы supabase.
