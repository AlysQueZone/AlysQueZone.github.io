# 13: Ежедневный вход выдается сам, без кнопок

**What to build:** Ежедневный вход — не кнопка и не модалка с выбором, а автовыдача: при первом заходе вошедшего Чатерса в новый день серверный клейм срабатывает сам, а экран показывает всплывающее уведомление «Ежедневный вход: +N (день streak M)» без кнопок «забрать»/«нет» вообще. Уведомление гаснет само через few секунд, клик вне его тоже закрывает.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Кнопка «Ежедневный вход» и модалка с выбором удалены из шапки; ручного «забрать» больше нет
- [ ] Первый заход залогиненного в новый день (день — UTC, как на сервере) сам вызывает клейм; повторных вызовов в тот же день нет
- [ ] Уведомление показывает только факт: сумма + день streak; кнопок нет; автозакрытие + клик вне закрывает
- [ ] Гость без сессии ничего не получает и не видит лишнего; `npm run build` зелёный
