# 17: Модалка Гамбы — больше, чище, без мусора

**What to build:** Модалка Гамбы выглядит как аттракцион, а не таблица: окно чуть больше, колесо — 10 крупных сегментов как раньше (3 мимо / 4 малых / 2 средних / 1 джекпот — визуальная аппроксимация, точные веса 30/40/22/8 живут в БД и плакате), плакат — 4 чистые строки («мимо — 30%», «+50 — 40%», «+200 — 22%», «Джекпот ×10 — 8%») плюс строка ставки, без строк-дублей выплат и без хвастовства про сервер. Тексты победы/поражения переписаны: короткие, в тоне канала, без бреда (для мимо/малого/среднего/джекпота + legacy-возврат).

**Blocked by:** None (can start immediately, только клиент).

**Status:** ready-for-agent

- [ ] Окно шире (колесо крупнее, на 360px ничего не вылезает за края)
- [ ] Колесо — 10 сегментов 3/4/2/1; исход по-прежнему решает сервер, колесо докручивается до сегмента выпавшего типа
- [ ] Плакат: ставка + 4 строки исходов, дублей чисел и серверного хвастовства нет; при чтении конфига из БД формат тот же
- [ ] Тексты результатов для 5 ключей (miss/small/big/jackpot/return) — тон канала, по делу; `npm run build` зелёный
