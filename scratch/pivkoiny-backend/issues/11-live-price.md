# 11: Живая цена перекупа и похороны localStorage

**What to build:** «Забрать за N» везде берётся из подписки на БД (кнопка перекупа, колокол, карточка), открытая модалка live-обновляет цену, клиентская формула next-цены удалена из обоих мест.
