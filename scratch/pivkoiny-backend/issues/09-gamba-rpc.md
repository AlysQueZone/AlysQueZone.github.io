# 09: Гамба крутится на сервере со ставкой 100

**What to build:** Колесо играет по-взрослому: спин стоит 100, исход считает сервер одним вызовом (дебет ставки + кредит выигрыша + возврат исхода), клиент лишь рисует присланное.
