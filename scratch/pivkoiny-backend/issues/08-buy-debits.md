# 08: Покупка списывает Пивкойны с БД

**What to build:** Нажатие «Да, забираю» списывает цену сервера со счёта покупателя (и кредитует продавца при перекупе) в той же транзакции, что и запись покупки. Гейт «хватит/не хватит» — серверный; итог показывает фактически уплаченное. Пауза 30с, кап 10/10мин, цена +10% и блокировки — без изменений.

**Blocked by:** 07 (нужен счёт и баланс).

**Status:** ready-for-agent

- [ ] Покупка без денег отклоняется сервером (`insufficient funds`), клиент показывает честный отказ в тоне канала
- [ ] Успешная покупка: дебет покупателя + кредит продавцу + строки леджера, баланс сошёлся с суммой движений
- [ ] Прямой обход UI (INSERT руками) не даёт купить без денег и не меняет цену/identity
- [ ] Пауза, кап, потолок цены, свой лот — регрессия старых сценариев; `npm run build` зелёный
