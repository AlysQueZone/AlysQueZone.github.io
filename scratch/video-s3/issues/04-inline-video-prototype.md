# Инлайн-видео в карточке вместо кнопки «слушать»

Type: prototype
Status: resolved

## Answer

Человек выбрал глазами 2026-09-08: **V2 — постер + play в карточке**. Поведение: в карточке/на странице лота рисуется webp-постер с оверлеем «▶ смотреть»; клик заменяет постер на инлайн-`<video controls autoplay playsinline>` (webm + mp4-фолбэк); трафика до клика нет (только webp ~7 КБ). Один компонент на `LotCard` и `lots/[id]`, работает и с хотлинком MemeAlerts, и с будущими URL из Supabase (поле `video_url` + замена хвоста). При покупке в `BuyModal` играет **видео лота со звуком** (вместо `entry.audio`/хлопков); clap остаётся фолбэком для лотов без видео. При мёртвом URL остаётся постер (ошибка видео не ломает карточку) — деталь для спеки.
Прототип-артефакт: `scratch/video-s3/prototype/inline-video.html` (throwaway, открыт двойным кликом; оставлен в `scratch` на `main` по прецеденту репо вместо отдельной ветки). V1 (автоплей) и V3 (модалка) отвергнуты. Разблокированных зависимостей не осталось; дальше — маппинг и пайплайн.

## Question

Человек решил: видео смотрится инлайн прямо в карточке. Как именно: `<video>` вместо `poster`+кнопки «▶ слушать» в `LotCard.astro` и на странице `lots/[id].astro`, поведение (muted loop autoplay vs click-to-play с controls), что играет при покупке в `BuyModal.astro` (раньше `entry.audio` через `new Audio`), превью-фолбэк при мёртвом URL, мобильный трафик, переиспользование для хотлинка MemeAlerts и supabase-файлов одним компонентом. Прототип — дешёвый throwaway (статичный html или ветка) с 2–3 вариантами поведения, человек выбирает глазами. Заблокировано: нужны реальные URL-приёмы (02) и поле модели (03).
