# 07: Кликабельный покупатель в колокольчике

**What to build:** В панели «Перекупы твоих лотов» ник покупателя становится ссылкой на его профиль; кнопка «перекуп» и остальное поведение панели не ломаются.

**Blocked by:** 01 — Публичный профиль: данные, паспорт, страница.

**Status:** resolved

- [x] Записи колокольчика — и живые, и догнанные офлайн — несут `buyer_uid` вместе с логином.
- [x] Ник покупателя в панели ведёт на `/profile/?uid=<buyer_uid>`.
- [x] Кнопка «перекуп» остаётся кликабельной и не перекрывается ссылкой; фокус видим.
- [x] Панель не открывает новый realtime-канал и не меняет существующий поток событий.
- [x] Тесты маппера колокольчика дополнены `buyer_uid`.
- [x] Проверено в `preview`/локальном Supabase живым перекупом и догоном после перезагрузки.

## Comments

Реализовано: `buyer_uid` в `LiveOutbid`/`OutbidEvent` — живой дифф берёт uid нового владельца, догон выбирает `buyer_uid` из `purchases`; ник в панели — ссылка (`src/lib/profile-link.ts`), «перекуп» остаётся соседней кнопкой, дедуп и поток событий не тронуты, `innerHTML` не используется.
Тесты маппера и предложения дополнены; проверено в preview живым перекупом и догоном после перезагрузки.
