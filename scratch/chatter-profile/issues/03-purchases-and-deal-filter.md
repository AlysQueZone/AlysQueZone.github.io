# 03: История покупок на профиле и фильтр лога по чатерсу

**What to build:** На профиле видны последние пять покупок и ссылка «Вся история →» на существующий лог сделок. Лог получает фильтр `?user=<uid>` по покупателю и заголовок «Покупки @nick», без новой страницы и новых кнопок.

**Blocked by:** 01 — Публичный профиль: данные, паспорт, страница.

**Status:** ready-for-agent

- [ ] Профиль показывает последние пять покупок: дата, название привета и цена; строка ведёт на страницу привета.
- [ ] «Вся история →» ведёт на `/deals/?user=<uid>`; полная история открывается в существующем логе.
- [ ] Лог с `?user=<uid>` показывает только покупки этого покупателя, с листанием и живыми обновлениями.
- [ ] Заголовок лога в этом состоянии — «Покупки @nick»; если логин не найден, честный фолбэк без выдуманного ника.
- [ ] Кнопки «Все» и «Мои покупки» остаются единственными выходами и сбрасывают `user`; новых кнопок нет.
- [ ] Возврат к фильтру чатерса после «Все» работает браузерной «назад».
- [ ] Гость может открыть фильтр по чужому uid; «Мои покупки» без входа по-прежнему показывает подсказку.
- [ ] Пустое состояние и ошибка чтения выглядят как в существующем логе.
- [ ] Чистое ядро фильтра (разбор `?user`/`?mine`, buyer uid, заголовок, URL) покрыто тестами.
- [ ] Проверено в `preview`: переход с профиля, листание, «Все», «Мои покупки», пустой и неизвестный uid.
