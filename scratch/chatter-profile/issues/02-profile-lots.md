# 02: Приветы на профиле: K1 и переезд «Моих приветов»

**What to build:** Профиль показывает приветы во владении компактными карточками K1, листает их по 12 и позволяет купить чужой привет прямо оттуда. «Мои приветы» переезжают с витрины на профиль; на `/lots/` остаётся ссылка.

**Blocked by:** 01 — Публичный профиль: данные, паспорт, страница.

**Status:** resolved

- [x] Приветы профиля читаются страницами по курсору `(price, slug)` и индексу владельца; размер страницы — 12.
- [x] Компактная карточка K1: кадр 77:136, название, цена и кнопка; две колонки на широком, одна на телефоне; строки владельца нет.
- [x] Карточка использует общие слоты представления Лота: ссылка на привет, кадр, бейджи, кнопка покупки и существующая модалка покупки.
- [x] Свой привет показывает погашенную кнопку «Твой лот»; чужой — «▶ Забрать»; покупка проходит через серверный гейт.
- [x] «Показать ещё» листает приветы и подгружается при прокрутке, как на витрине; пустое состояние — «Пока нет приветов».
- [x] После сделок профиль перечитывает статы и первую страницу приветов по сигналу модуля живых данных, без нового realtime-канала.
- [x] С `/lots/` убрана полная секция «Мои приветы»: залогиненному — ссылка на свой профиль, гостю — прежняя подсказка входа.
- [x] ADR 0009 обновлён: компактная раскладка — вариант того же представления, а не вторая Карточка Лота.
- [x] Проверено в `preview`: свой и чужой профиль, покупка с чужого профиля, мобильная раскладка, пусто и ошибка.

## Comments

Реализовано: `LotCardCompact`/`LotCardCompactSkeleton` как раскладка того же представления Лота (ADR 0009), `readOwnerLotsPage` в `src/lib/live.ts`, страницы по 12 с «Показать ещё» и автоподгрузкой, «Твой лот» для своего, общая модалка покупки; с `/lots/` убрана полная секция «Мои приветы» — залогиненному ссылка, гостю подсказка входа.
Проверено в preview: 14 лотов — 12 и подгрузка, свой и чужой профиль, живая покупка с чужого профиля через серверный гейт, пустой профиль, ошибка первой страницы с повтором, телефон в одну колонку.
