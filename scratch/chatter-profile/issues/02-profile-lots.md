# 02: Приветы на профиле: K1 и переезд «Моих приветов»

**What to build:** Профиль показывает приветы во владении компактными карточками K1, листает их по 12 и позволяет купить чужой привет прямо оттуда. «Мои приветы» переезжают с витрины на профиль; на `/lots/` остаётся ссылка.

**Blocked by:** 01 — Публичный профиль: данные, паспорт, страница.

**Status:** ready-for-agent

- [ ] Приветы профиля читаются страницами по курсору `(price, slug)` и индексу владельца; размер страницы — 12.
- [ ] Компактная карточка K1: кадр 77:136, название, цена и кнопка; две колонки на широком, одна на телефоне; строки владельца нет.
- [ ] Карточка использует общие слоты представления Лота: ссылка на привет, кадр, бейджи, кнопка покупки и существующая модалка покупки.
- [ ] Свой привет показывает погашенную кнопку «Твой лот»; чужой — «▶ Забрать»; покупка проходит через серверный гейт.
- [ ] «Показать ещё» листает приветы и подгружается при прокрутке, как на витрине; пустое состояние — «Пока нет приветов».
- [ ] После сделок профиль перечитывает статы и первую страницу приветов по сигналу модуля живых данных, без нового realtime-канала.
- [ ] С `/lots/` убрана полная секция «Мои приветы»: залогиненному — ссылка на свой профиль, гостю — прежняя подсказка входа.
- [ ] ADR 0009 обновлён: компактная раскладка — вариант того же представления, а не вторая Карточка Лота.
- [ ] Проверено в `preview`: свой и чужой профиль, покупка с чужого профиля, мобильная раскладка, пусто и ошибка.
