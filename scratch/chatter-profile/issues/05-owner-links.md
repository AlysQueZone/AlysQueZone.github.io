# 05: Кликабельный владелец на Карточке Лота и странице Лота

**What to build:** Ник владельца на Карточке Лота и на странице Лота становится ссылкой на профиль. «Свободен» и «Биржа» остаются текстом.

**Blocked by:** 01 — Публичный профиль: данные, паспорт, страница.

**Status:** resolved

- [x] Бейдж владельца на Карточке Лота ведёт на `/profile/?uid=<owner_uid>`.
- [x] Бейдж владельца на странице Лота ведёт туда же.
- [x] Свободный лот и «Биржа» ссылкой не становятся.
- [x] Ссылка сохраняет вид бейджа, не ломает клик по кадру и кнопке покупки, имеет видимый фокус и доступное имя.
- [x] На профиле строка владельца по-прежнему не выводится: там все приветы принадлежат хозяину профиля.
- [x] Проверено в `preview`: витрина, свободный лот, страница Лота, свой и чужой лот; клавиатура.

## Comments

Реализовано: `ownerBadgeView` в `src/lib/lot-view.ts`, `[data-owner-badge]` — настоящая ссылка `<a>` на профиль владельца на витрине и странице Лота; свободный лот, «Биржа» и пустой uid остаются текстом; K1 по-прежнему без строки владельца, бейджи владельца/свободен там скрыты.
Проверено в preview: клик по бейджу открывает профиль и не открывает окно покупки, Tab доводит до бейджа с видимым фокусом, мобильная раскладка не разъезжается.
