# 04: Шапка: ник и плашка баланса — ссылки, «Выйти» — на профиле

**What to build:** В шапке ник и плашка баланса ведут в свой профиль. Кнопка «Выйти» из шапки убирается и остаётся только на своём профиле. Гость по-прежнему видит «Войти через Twitch».

**Blocked by:** 01 — Публичный профиль: данные, паспорт, страница.

**Status:** resolved

- [x] Залогиненный чатерс видит в шапке ник-ссылку на `/profile/?uid=<свой uid>`.
- [x] Плашка баланса — ссылка на свой профиль; гостю она не показывается.
- [x] Кнопки «Выйти» в шапке больше нет; выход доступен на своём профиле и завершает сессию.
- [x] Гость видит «Войти через Twitch»; после входа шапка перерисовывается без перезагрузки страницы.
- [x] Ссылки в шапке оформлены как соседние аркадные кнопки, без отдельного фона-плашки, и имеют видимый фокус.
- [x] Проверено в `preview` и на локальном Supabase: гость, залогиненный, выход, возврат после выхода.

## Comments

Реализовано: ник и плашка баланса в шапке — ссылки в свой профиль через `profileHref` (`src/lib/header.ts`), кнопка «Выйти» из шапки удалена и живёт только в паспорте своего профиля; гость по-прежнему видит «Войти через Twitch», плашки нет. Стиль — соседние аркадные ghost-кнопки, фокус видим, шапка обновляется существующими путями без перезагрузки.
Проверено в preview и на локальном Supabase: гость, залогиненный, выход и возврат гостем; настоящий Twitch-OAuth локально не воспроизводится.
