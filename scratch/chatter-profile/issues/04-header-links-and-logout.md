# 04: Шапка: ник и плашка баланса — ссылки, «Выйти» — на профиле

**What to build:** В шапке ник и плашка баланса ведут в свой профиль. Кнопка «Выйти» из шапки убирается и остаётся только на своём профиле. Гость по-прежнему видит «Войти через Twitch».

**Blocked by:** 01 — Публичный профиль: данные, паспорт, страница.

**Status:** ready-for-agent

- [ ] Залогиненный чатерс видит в шапке ник-ссылку на `/profile/?uid=<свой uid>`.
- [ ] Плашка баланса — ссылка на свой профиль; гостю она не показывается.
- [ ] Кнопки «Выйти» в шапке больше нет; выход доступен на своём профиле и завершает сессию.
- [ ] Гость видит «Войти через Twitch»; после входа шапка перерисовывается без перезагрузки страницы.
- [ ] Ссылки в шапке оформлены как соседние аркадные кнопки, без отдельного фона-плашки, и имеют видимый фокус.
- [ ] Проверено в `preview` и на локальном Supabase: гость, залогиненный, выход, возврат после выхода.
