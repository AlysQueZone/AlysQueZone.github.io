# 01: Продавец сделки в БД и настоящий продавец в истории перепродаж

**What to build:** Открыв любой лот на витрине, чатерс видит в «Истории перепродаж» настоящего продавца каждой сделки: у лота из заявки первая строка показывает автора привета (того же, кто подписан «Привет добавил»), у ничейного лота (лота админа) — «Биржа», в остальных строках — того, кто владел лотом до сделки. Само-переходов вида `X → X` не остаётся ни у одного лота. Заодно история сделок лота перестаёт подрезаться: в БД она хранится целиком, поэтому первая сделка лота не потеряется с ростом числа перекупов, и страница лота показывает всю историю.

Спека: `scratch/purchase-seller/spec.md`.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] У каждой новой покупки в БД записан продавец — владелец лота до сделки; у ничейного лота продавца нет (пустое значение), и это значит именно «продавца не было», а не «неизвестно».
- [ ] Продавца пишет серверный код, а не клиент: подделать его клиентским запросом нельзя.
- [ ] Старые сделки забэкфиллены: продавец = предыдущий покупатель по времени сделки внутри лота, а у первой строки лота — автор привета, если владельца назначали при приёме заявки (у лота, чей автор удалил аккаунт до приёма, продавца не было — там пусто).
- [ ] История сделок лота не подрезается: новые сделки не удаляют старые, число строк растёт вместе с числом сделок. Строки, потерянные до этой правки у трёх старых лотов, не восстанавливаются — данных о них нигде нет (принятый компромисс, костылей под них не делаем).
- [ ] Новый чистый модуль чтения сделок превращает строки в записи истории перепродаж: продавец из БД, у ничейного лота — «Биржа», порядок входной, покупатель и цена как есть.
- [ ] Модуль покрыт тестами ядра (vitest, без DOM): лот из заявки, ничейный лот, пустая история, пометка «ТВОЙ» по uid покупателя, порядок записей.
- [ ] Страница лота читает историю через этот модуль: параметр «владелец из каталога», реконструкция цепочки и лимит 50 ушли; пустое состояние, цены и пометка «ТВОЙ» работают как раньше.
- [ ] В `preview` на лоте из заявки первая строка показывает автора, на ничейном лоте — «Биржа»; ни одной строки `X → X`.
