# Сообщение в Telegram и пайплайн агента «id → карточка»

Status: resolved
Type: grilling
Blocked by: 01, 05

## Question

Что приходит админу в Telegram и что делает агент по id заявки?

- Состав сообщения: id (главное — админ пересылает его агенту), ник, название, ссылка/файл, комментарий, ссылка на страницу лота после принятия — по желанию.
- Пайплайн агента: где документируется (черновик — новый `docs/agents/submissions.md` + указатель в `AGENTS.md`; `media-pipeline.md` не трогаем или ссылаемся), что делает по id: забирает заявку, получает видео (по ссылке или из Storage), проверяет смысл, собирает тройку media + карточку `content/lots.toml` по `media-pipeline.md`, `just lots-sync`, помечает заявку принятой, инициирует начисление награды. Что делает при отказе.
- Нужен ли `just`-рецепт (например, `just submission <id>`) и какой.
- Ответ: шаблон сообщения + шаги пайплайна + куда записаны.

## Answer

**Сообщение админу** (без разворачивания ссылки — `link_preview_options.is_disabled`):

```
🍺 Заявка #<id>
Название: <title>
От: @<author_login>
Ссылка: <video_url>
💬 <comment>
```

Комментарий — строкой только если он есть. `id` первым: админ пересылает его агенту. Транспорт — по тикету 01 (`after insert`-триггер → pg_net → Telegram, секреты в Vault); сбой уведомления не откатывает заявку.

**Пайплайн агента** — новый `docs/agents/submissions.md` + указатель в `AGENTS.md`; `media-pipeline.md` остаётся, на него ссылаемся.

- `just submission <id>`: читает заявку; скачивает видео по ссылке локально (`yt-dlp`/`ffmpeg`); проверяет, что это по смыслу привет; собирает тройку media и карточку `content/lots.toml` по `media-pipeline.md` (заголовок — из заявки с резолвом ника по `docs/agents/chatters.md`; слаг — новый уникальный); `just lots-sync`; связывает `lot_id`; ставит `accepted`; начисляет +500 через `pay_submission_reward`.
- `just submission-reject <id>`: статус `rejected` (или `duplicate`, если привет уже на бирже), без выплаты.
- Отказ — всегда решение человека (вариант a): при проблемах (мёртвая/приватная ссылка, не похоже на привет, дубликат) агент останавливается и докладывает, а не решает сам.
