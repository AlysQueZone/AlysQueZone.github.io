# 09: Уведомление Админу в Telegram

Status: ready-for-agent
Blocked by: 08
Спека: [`spec.md`](../spec.md)

## What to build

Когда заявка появляется, Админу приходит сообщение в Telegram: номер заявки первым, затем название, ник, ссылка
и комментарий (если он был), без разворота ссылки. Токен бота и chat_id хранятся в секретах базы, в код и git не
попадают. Если Telegram недоступен, заявка всё равно сохраняется и приём не ломается.

Разовая ручная настройка (делает человек): завести бота у @BotFather, нажать боту `/start`, получить `chat_id`,
положить токен и `chat_id` в секреты.

## Acceptance criteria

- [ ] Новая заявка приводит к сообщению в Telegram, где номер заявки — первым.
- [ ] Сообщение содержит название, ник и ссылку; комментарий — если он был.
- [ ] Ссылка не разворачивается превью.
- [ ] При недоступном Telegram заявка сохраняется, пользователь не видит ошибку отправки.
- [ ] Секреты бота отсутствуют в репозитории и в клиентском бандле.
