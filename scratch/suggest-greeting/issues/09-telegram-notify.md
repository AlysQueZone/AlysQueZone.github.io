# 09: Заявка приходит админу в Telegram

**What to build:** Каждая новая заявка отправляет админу сообщение в Telegram с номером, названием, ником, ссылкой и комментарием — номер первым, чтобы его можно было переслать агенту. Секреты бота живут только на сервере; сбой отправки не мешает заявке сохраниться.

**Blocked by:** 08.

**Status:** ready-for-agent

- [ ] Триггер на вставку заявки шлёт сообщение формата из спеки (без превью ссылки; комментарий — строкой, только если есть).
- [ ] Токен бота и chat_id лежат в Supabase Vault; в git не попадают; есть runbook настройки и ротации.
- [ ] Ошибка отправки не откатывает заявку; локально без секретов уведомление тихо не отправляется.
- [ ] Человеческий шаг выполнен: бот создан, `/start` нажат, chat_id получен, секреты в Vault.
- [ ] Проверено: живая заявка → сообщение в Telegram; при недоступном Telegram заявка остаётся в базе.
