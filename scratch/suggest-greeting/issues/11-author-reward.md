# 11: Награда автору: +500 и 3% с первых трёх перекупов

Status: ready-for-agent
Blocked by: 10
Спека: [`spec.md`](../spec.md)

## What to build

При принятии заявки автору один раз начисляется 500 Пивкойнов. Пока лот перекупают первые три раза, 3% цены
каждой сделки уходят автору из комиссии биржи (в правилах: комиссия 7% — 4% сгорает, 3% автору); начиная с
четвёртого перекупа — только комиссия. Все движения попадают в журнал баланса. Повторное начисление за одну
заявку невозможно; выплата не проходит по удалённому аккаунту автора.

## Acceptance criteria

- [ ] После принятия заявки автор получает +500 ровно один раз.
- [ ] На первых трёх перекупах лота автор получает по 3% цены сделки.
- [ ] На четвёртом и последующих перекупах автору ничего не начисляется.
- [ ] Движения видны в журнале: разовая награда и роялти — отдельными источниками.
- [ ] Повторный запуск принятия не начисляет награду второй раз.
- [ ] При удалённом аккаунте автора выплаты не проходят, история лота не ломается.
