# 10: Агент собирает лот из заявки (принятие и отказ)

Status: ready-for-agent
Blocked by: 08
Спека: [`spec.md`](../spec.md)

## What to build

По номеру заявки админ одной командой принимает привет: агент скачивает видео по ссылке, проверяет, что это по смыслу привет, готовит медиа-тройку и карточку, публикует лот на витрине, связывает его с заявкой, пишет автора и ставит статус «принята». Отдельная команда фиксирует отказ или дубликат без выплаты. При проблемах агент останавливается и спрашивает человека. На странице принятого лота появляется подпись «Привет добавил: <ник>».

## Acceptance criteria

- [ ] `just submission <id>` проходит весь путь: заявка → скачанное видео → медиа по существующему пайплайну → карточка в контенте → синк → связанный лот на витрине.
- [ ] Заголовок берётся из заявки с резолвом ника по реестру, слаг — новый уникальный.
- [ ] Заявка получает статус «принята», связь с лотом и автора; страница лота показывает «Привет добавил: <ник>», в списках витрины подписи нет.
- [ ] `just submission-reject <id>` ставит «отклонена» или «дубликат»; выплат не делает.
- [ ] Пайплайн описан документом для агента + указатель в `AGENTS.md`; при мёртвой ссылке, не-привете или дубликате агент останавливается и докладывает.
- [ ] Проверено: принятая заявка видна как лот с подписью; отклонённая не появляется.
