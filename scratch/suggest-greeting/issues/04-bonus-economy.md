# Экономика награды за принятую заявку

Status: resolved
Type: grilling
Blocked by: none

## Question

Что получает отправитель, чья заявка принята на биржу?

- Награда идёт отправителю заявки (выбор владельца). Деньги — только серверно: `profiles.balance` + append-only `ledger`; сейчас есть источники `seed_opening`, `purchase_debit`, `purchase_credit`, `commission_burn`, `gamba_stake`, `gamba_win`, `daily_login`.
- Ограничения экономики: комиссия 7% (ceil, min 1) сжигается; первые 15 перекупов — `ceil(+10%)`, дальше `+1`; старт 1000; витрина обязана показывать живые правила («Правила биржи», бегущая строка) — математика из одних рук.
- Подготовить и обсудить варианты с цифрами (числа + сценарии перекупов): разовый бонус (сколько и откуда — из воздуха или из чего-то), процент от перекупов (роялти: сколько, от чьей доли, как складывается с комиссией), гибрид, другое.
- Крайние случаи: отказ, дубликат, повторная заявка; можно ли получить награду за один привет дважды; что если лот ни разу не перекупили.
- Ответ: выбранная механика + точные числа + строки леджера + что править в `CONTEXT.md`, «Правилах биржи» и бегущей строке.

## Comments

Материал к решению: [`research/bonus-economy-options.md`](../research/bonus-economy-options.md) — текущие потоки денег, варианты A/B/C/D с числами, симуляция на 28 лотах (цены сошлись с продом 7/7), влияние на денежную массу, требования к схеме. Рекомендация отчёта — A, N=500.

## Answer

Выбор владельца: **гибрид — +500 сразу при принятии и 3% с первых 3 перекупов** (пресет C из отчёта, но бонус 500 вместо 250):

- **разовый бонус**: +500 один раз при принятии заявки, источник леджера `submission_bonus` (mint; идемпотентный RPC для `service_role`);
- **роялти**: 3% от цены сделки, **только за первые 3 перекупа**, из комиссии (7% = 4% сгорает + 3% автору), источник `royalty_credit`, ставка — `royalty_rate()`;
- масштаб: на 28 лотов — 14 000 бонусов + 2 784 роялти; на один лот 579–645 (500 + 79–145); хвоста нет;
- правила краёв: дубликат/повторная заявка — выплата одна (привязана к id заявки); заявка на привет, который уже на бирже, отклоняется как дубликат без награды; аккаунт автора удалён — выплаты прекращаются (`author_uid on delete set null`), разовая не откатывается;
- от самофарма: лимит **не больше 10 открытых заявок за раз** на чатерса; ужесточим, если станет реальной проблемой;
- в UI тонкости не выносим; в «Правилах биржи» — только сама награда (математика из одних рук).

Побочно: расхождение леджера 1 840 объяснено — владелец в первые дни вручную выдавал пивкойны через web-UI (не баг; см. дополнение в отчёте).
