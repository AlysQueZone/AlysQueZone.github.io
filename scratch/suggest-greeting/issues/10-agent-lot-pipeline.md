# 10: Агент: заявка → лот с подписью

Status: ready-for-agent
Blocked by: 08
Спека: [`spec.md`](../spec.md)

## What to build

По номеру заявки агент собирает лот: скачивает видео по ссылке, проверяет, что это по смыслу привет, готовит
медиа и карточку по существующему медиа-пайплайну, публикует каталог, связывает лот с заявкой и переводит её в
статус «принята». На подробной странице лота появляется подпись «Привет добавил: <ник>». Отдельная команда
фиксирует отказ (или дубликат, если привет уже на бирже) без выплаты и без лота. При проблемах (мёртвая или
приватная ссылка, не похоже на привет) агент останавливается и спрашивает человека.

## Acceptance criteria

- [ ] По номеру заявки лот появляется в витрине и открывается по своей странице.
- [ ] На подробной странице лота видно «Привет добавил: <ник>».
- [ ] Заявка связана с лотом и находится в статусе «принята».
- [ ] Отказ переводит заявку в «отклонена»/«дубликат» без выплаты и без лота.
- [ ] Пайплайн описан в документации для агента, указатель добавлен в `AGENTS.md`.
- [ ] При мёртвой ссылке или спорном видео агент останавливается и докладывает.
