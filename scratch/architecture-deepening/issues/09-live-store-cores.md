# 09: live-store — три внутренних владельца

Type: grilling
Status: resolved
Blocked by: 01, 03, 04, 05

## Question

Как разложить `live-store` на три внутренних владельца с узкими интерфейсами — срез каталога, баланс/церемония, сессия/«Мои приветы» — сохранив фасад `LiveStore` на время перехода и превратив `mine` в селектор?

Ревью: `review.md`, карточка «live-store — один объект на шесть доменов».

## What to grill

- Strangler: фасад сохраняется целиком; поверхности не меняются; тесты переводятся по одному ядру; когда фасад сужается.
- Три владельца: вход/выход, события, кто владеет коалесцингом и двумя дорожками дедупа.
- `mine`: убрать из `LotState`, селектор при чтении; `sameLot` / `withMine` / `normalizeMine` / `toLotState` — что уходит.
- `catalog()` vs `catalogWindow()`: типизировать разницу «окно / карта / мой список»; главная использует обе.
- Малые швы: `LivePayload` в ядре (транспорт переводит в доменное событие), fallback «вью/таблица», `reportDeal(payload?)`, `fitsCatalogWindow`.
- Session tri-state (`unknown | guest | user`): после тикета 02 остался малым швом; решить, входит ли во владельца «сессия» или в отдельный тикет.
- Как делить тесты: три файла и fake-читатели вместо одного harness на 1061 строку.
- Может ли карточка разбиться на несколько спек/тикетов; если да — записать task graph, не дробить сейчас.
- ADR impact: `none`; ADR-0003/0012 сохраняются.

## Recommended answers

> Решения, лёгшие в основу спеки: [specs/09-live-store-cores.md](../specs/09-live-store-cores.md).

1. **Strangler.** Фасад `LiveStore` / `live.*` и поверхности не меняются; три владельца вводятся за фасадом; тесты переводятся по одному; сужение фасада — после всех трёх, отдельным шагом. Одна спека + task graph, не три тикета сейчас.
2. **Три владельца.** Срез каталога (режим/окно/курсор/вставка/дифф; вход — читатель страницы/по slug, тик; выход — окно + changed); баланс/церемония (defer/release/refresh, дедуп дорожек, последнее раскрытое); сессия/«Мои приветы» (uid, первое ожидание, полный список владельца). Коалесцинг — один планировщик в композиции/фасаде, не в каждом владельце; дедуп дорожек — у своего владельца.
3. **`mine`.** Убрать из `LotState`; `toLotState` больше не принимает uid; `withMine` / `normalizeMine` / сравнение `mine` в `sameLot` уходят; чистый `isMine(st, uid)`; `fillLot` получает `uid` в опциях и считает флаг один раз; поверхности передают `live.uid()`.
4. **`catalog()` / `catalogWindow()`.** Переименовать `catalog()` в `catalogMap()` (карта известных slug), `catalogWindow()` — окно в порядке показа, `myLots()` — полный список владельца; главная обновляет `refill` на `catalogMap()`. Три разных типа доступа, не два похожих имени.
5. **Малые швы.** `LivePayload` уходит из ядра: `reportLotsTick({insertedSlugs})`, `reportDeal({sellerUid?})`; `live.ts` разбирает Realtime-payload. Fallback «вью/таблица» остаётся в транспортных читателях `live.ts`; `fitsCatalogWindow` — правило среза каталога, остаётся и тестируется у него.
6. **Session tri-state.** Владелец «сессия» отдаёт `sessionState(): 'unknown' | 'guest' | 'user'` (из `uidKnown` / `uid`); фасад может его пробросить; миграция поверхностей с прямого `getSession` — вне карточки. Тесты — переходы unknown → guest/user и смена uid.
7. **Тесты.** Три файла — `live-store.catalog.test.ts`, `live-store.balance.test.ts`, `live-store.session.test.ts` — с fake-читателями; общие только фабрики читателей/событий; harness на 1061 строку исчезает; маленький тест фасада при необходимости.
8. **Дробление.** Одна спека с task graph на три шага (баланс/церемония → сессия/«Мои приветы» + `mine` → срез каталога) и отдельным шагом сужения фасада. Если один владелец не влезает в сессию — тогда дочерние тикеты, не сейчас.
9. **ADR.** `none`; ADR-0003/0012 сохраняются.

## Answer

Спека: [specs/09-live-store-cores.md](../specs/09-live-store-cores.md).

- Strangler: фасад `LiveStore`/`live.*` и поверхности не меняются; внутри три владельца — срез каталога, баланс/**Церемония**, сессия/**Мои приветы**.

- Владелец сессии отдаёт `sessionState(): unknown|guest|user`; миграция поверхностей с прямого `getSession` — вне карточки.
- Тесты делятся на три файла с fake-читателями; harness на 1061 строку исчезает.
- ADR impact — `none`: ADR-0003/0012 сохраняются.
